# 有理 · 中文辩论计时

一个面向中文课堂的轻量辩论设置与计时工具。无需登录、订阅、数据库或安装依赖。

## 功能

- 设置活动名、辩题、正反方队伍及各自观点。
- 36 道课堂辩题随机抽取，支持撤销和手动修改。
- 正反方独立设置 1–6 位辩友，自动生成一辩至六辩，可选填姓名。
- 10、20、30 分钟模板；可自定义环节、发言方、发言辩友和每方时长。
- 单方发言与双方独立计时；支持暂停、续计、换方、环节导航及提示音。
- 大屏投影与手机排版，浏览器限制全屏时仍可使用放大的投屏布局。
- 设置保存在当前浏览器，可导出、导入 JSON 备份。

## 使用

填写辩题 → 设置双方辩友和环节 → 点击「准备好了，进入赛场」→ 主持人点击开始计时。

选择「双方」时，每方分别拥有设置的时长，总时长会计入两份。自由辩论点击队伍卡片或按 A / D 换方。

快捷键：空格开始/暂停；左右方向键切换环节；A 正方、D 反方；F 投屏。

## 本地启动

在本目录运行：

```sh
python3 -m http.server 8010 --bind 127.0.0.1
```

浏览器打开 `http://localhost:8010`。请使用 HTTP 服务打开，直接双击 HTML 文件可能无法加载 JavaScript 模块。

## 测试

使用较新版本的 Node.js 运行：

```sh
node --test tests/debate_timer.test.mjs
```

## 数据与使用边界

网页不包含服务器端账号、数据收集或分析服务。辩题、队名、姓名仅保存在使用者当前浏览器的 localStorage；请妥善保管自己导出的设置文件。不同浏览器、设备或网站地址之间不会自动同步。

计时进度只保存在当前页面内存中。关闭、刷新或返回设置会重置计时；题目与环节设置仍会保留。适合一台电脑主持并投影给全班观看，不提供远程多人同步、录音或评分。
